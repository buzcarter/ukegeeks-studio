# Theme fonts

The editor's color themes use these nine fonts. Web pages load them from Google Fonts; the app bundles them so it works offline. `web/css/fonts.css` declares them.

Downloaded 2026-11-06 from the [google/fonts](https://github.com/google/fonts) repo (commit `86aced91de05`), one `-Regular.ttf` per family, unchanged.
