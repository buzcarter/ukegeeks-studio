UkeGeeks Studio's first beta: a desktop app for keeping your ukulele songs in songbooks, editing them in ChordPro and seeing the songsheet as you type. Thanks for trying it. It's a beta, so keep a copy of any songs you care about.

## Install

**Mac** (macOS 11 or later, Apple Silicon or Intel): download `UkeGeeks Studio_0.2.0-beta.1_universal.dmg`, open it and drag UkeGeeks Studio to Applications. It's signed and notarized by Apple, so it opens with no warning.

**Windows** (64-bit): download `UkeGeeks Studio_0.2.0-beta.1_x64-setup.exe` and run it. It isn't signed yet, so Windows says "Windows protected your PC": click **More info**, then **Run anyway**.

## What to try

- **Add a songbook:** File > Add Songbook to Library…, then pick a folder of `.cpm` (ChordPro) songs. The Library sidebar lists your songbooks, with Favorites and All Songs above them.
- **Open a song** from the list, or double-click a `.cpm` file in Finder or Explorer.
- **Edit a song:** Edit > Edit Song opens the ChordPro text beside the songsheet, which follows as you type. The ? in the Edit window's corner lists the shortcuts.
- **Make a new song** with the + in the top bar, star your favorites, and search every songbook by title, artist or lyrics (Cmd+F or Ctrl+F).
- **Print** a songsheet from File > Print.
